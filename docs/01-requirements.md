# 01 — المتطلبات

## 1. النطاق
منظومة واحدة لكل منزل، كل مكوناتها داخل المنزل، وتملكها الشركة وتنقلها بين المشتركين عند الحاجة. المراقبة عبر WiFi المنزل في المرحلة الأولى. الاستهداف الأولي: مجمع من 3500 منزل، نتوقع إقناع نحو 350.

## 2. أصحاب المصلحة
| الجهة | الاحتياج |
|---|---|
| المشترك | كهرباء مستقرة بلا انقطاع، سداد سهل، إشعارات واضحة |
| المشغل (الشركة) | تحصيل مضمون، حماية الأصول، رؤية كاملة للحالة |
| الفني | تركيب وصيانة وتبديل سريع للوحدة |

## 3. المتطلبات الوظيفية

| الرمز | المتطلب |
|---|---|
| F1 | **سجل الأصول:** لكل وحدة رقم تسلسلي ورمز QR، وتُربط بمشترك أو تُفك عنه دون تغيير برمجي |
| F2 | **الباقات:** حد تيار (6 / 8 / 10 A وأعلى كاستثناء)، وسعر الأمبير موسمي قابل للتعديل |
| F3 | **الدفع الإلكتروني** بلا وكلاء ميدانيين، مع تفعيل تلقائي فور السداد |
| F4 | **الإنفاذ المحلي** على الجهاز: حد التيار، وقطع عند الانتهاء، ورمز صلاحية موقّع يعمل بدون إنترنت |
| F5 | **الإشعارات:** قرب الانتهاء، وانخفاض الشحنة، وحمل زائد، وانقطاع مفاجئ، وعطل، مع تنبيه محلي (صفارة وLED) |
| F6 | **مكافحة السرقة:** مقارنة تيار الإنفيرتر والـBMS، وموازنة الطاقة، ومفتاح عبث |
| F7 | **لوحة المشتركين:** أخضر (فعّال)، برتقالي (قارب الانتهاء)، أحمر (موقوف/عطل/عبث)، رمادي (غير متصل)، مع الاستهلاك والقراءات |
| F8 | **تطبيق المشترك:** الحالة، والدفع، وتجميد الاشتراك، والتواصل مع المجهز |
| F9 | **صحة الأصل:** درجة الحرارة، وعدد الدورات، وSOH لكل بطارية |
| F10 | **التجميد للمسافر:** إيقاف احتساب المدة المدفوعة لفترة محددة |
| F11 | **مؤشر كفاية الشحن:** الشحنة في نهاية كل فترة تجهيز وطني، لكشف المشتركين الذين يتجاوز استهلاكهم قدرة المنظومة |

## 4. المتطلبات غير الوظيفية

| الفئة | المتطلب |
|---|---|
| الاعتمادية | العمل كاملاً دون إنترنت حتى انتهاء صلاحية الرمز، وقرارات الحماية محلية دائماً |
| الأمان السيبراني | شهادة X.509 لكل جهاز، وTLS، وأوامر وتحديثات موقّعة |
| السلامة | منع التغذية العكسية للشبكة، وحماية حرارية، وتركيب مؤهل |
| التوسع | 350 جهازاً الآن، وقابلية 3500 |
| الواجهة | عربية (RTL) |
| الكلفة | هدف لتكلفة العتاد للوحدة يُحدد في مرحلة العتاد |
| القابلية للنقل | هوية الجهاز مستقلة عن المشترك |

## 5. قواعد الأعمال

1. **الدفع مسبق** شهرياً. لا مهلة بعد الانتهاء.
2. **الإشعارات** (مقترحة): قبل 3 أيام، ثم قبل يوم، ثم صباح يوم الانتهاء.
3. **ساعة قطع ثابتة** نهاراً، وليس ليلاً.
4. **عند السداد** يُعاد التفعيل فوراً.
5. **التجميد:** المشترك يطلب تجميد مدة محددة، ولا يُحتسب الاشتراك خلالها.
6. **الباقة الأعلى** تُمنح بعد التأكد من كفاية الشحن وساعات الوطنية في المنطقة.
7. **سعر الأمبير** موسمي: صيف 8 أشهر، شتاء 4 أشهر.
8. **الفوترة حسب الاستهلاك:** خيار مستقبلي غير معتمد في البداية.
