# 03 — تصميم العتاد

> كل القيم هنا أهداف تصميمية للمراجعة، وليست مواصفات نهائية.

## 1. سلسلة القدرة

```
الوطنية (AC) ─► إنفيرتر هجين ◄─► بطارية LiFePO4 48V / 15 kWh
ألواح (اختيارية) ─► (MPPT داخل الإنفيرتر)
إنفيرتر ─► عداد AC ─► كونتاكتور AC ─► لوحة المنزل
```

## 2. معايير اختيار المكوّنات

### الإنفيرتر الهجين (5 kW)
- منفذ **RS485/Modbus** موثق، لقراءة تيار/جهد البطارية والشبكة والخرج.
- تيار شحن **قابل للبرمجة** (لتحديد الشحن من الوطنية).
- وضع **Zero Export / منع التغذية العكسية**.
- مسار **Bypass** وتحويل سريع (زمن انقطاع صفري تقريباً).
- دعم بروتوكول BMS عبر CAN أو RS485.
- مثال لعائلات منتجات: Deye وGrowatt وVoltronic وSunsynk (تُراجع أوراق البيانات قبل الاختيار).

### البطارية (15 kWh)
- LiFePO4 مع **BMS** يدعم CAN ويقدّم: الجهد، والتيار، وSOC، وSOH، ودرجات الحرارة، وعدد الدورات.
- حماية داخلية (زيادة تيار، وقصر، وحرارة).
- نطاق تشغيل حراري مناسب لحرارة العراق، ومعلومات الضمان.

### المتحكم المحلي (يُصمم داخلياً)

| الوحدة | الوظيفة |
|---|---|
| ESP32 (WiFi/BLE) | المعالج والاتصال |
| ترانسيفر RS485 | قراءة الإنفيرتر |
| ترانسيفر CAN | قراءة الـBMS |
| IC قياس AC (مع CT) | جهد وتيار وقدرة الخرج |
| قاد ريلاي/كونتاكتور | القطع والوصل |
| RTC مع بطارية احتياطية | وقت موثوق للرمز الموقّع |
| حساس حرارة (NTC) | حرارة الصندوق |
| صفارة وLED | تنبيه محلي بلا إنترنت |
| مفتاح عبث | كشف فتح الصندوق |
| تغذية من خرج الإنفيرتر | يبقى المتحكم حياً على البطارية |
| Watchdog | إعادة تشغيل عند التعليق |

**المرحلة الثانية:** شنت DC مستقل عند البطارية داخل صندوق مختوم (طبقة إضافية ضد السحب الخفي).

## 3. حسابات الأبعاد

### 3.1 الباقات مقابل زمن التحمل
نافذة استخدام 80% (نحو 12 kWh)، وحمل عند الحد الأقصى للاشتراك طوال الوقت (أسوأ حالة نادرة):

| الباقة | القدرة | زمن التحمل |
|---|---|---|
| 6 A | 1.3 kW | نحو 9 ساعات |
| 8 A | 1.8 kW | نحو 7 ساعات |
| 10 A | 2.2 kW | نحو 5.5 ساعة |
| 15 A | 3.3 kW | نحو 3.6 ساعة |
| 22 A | 4.8 kW | نحو 2.5 ساعة |

### 3.2 الأيام السيئة (ساعتا تشغيل / أربع إطفاء)
خلال التشغيل يجب أن تشحن الوحدة ما استهلكته في الإطفاء وتغذي الحمل في آن واحد:

```
P_grid = P · ( 1 + t_off / (t_on · η) )
```

مع t_on = 2 h وt_off = 4 h وη ≈ 0.92 يكون `P_grid ≈ 3.17 · P`.

| متوسط الحمل | الطاقة المطلوبة من الوطنية | الحكم |
|---|---|---|
| 1.0 kW | نحو 3.2 kW | مريح |
| 1.5 kW | نحو 4.8 kW | على الحد |
| 2.2 kW | نحو 7 kW | غير ممكن (فوق 5 kW) |

**الاستنتاج:** المتوسط الأقصى المستدام نحو 1.5 kW (نحو 7 A فعلية) عند قدرة 5 kW. قدرة الشاحن الفعلية وقاطع الدخول في المنزل يخفضان هذا الرقم، فيُتحقق منها بالمسح قبل التركيب.

### 3.3 عمر البطارية
نحو 4 دورات جزئية يومياً في الأسوأ ≈ 1.4 دورة مكافئة كاملة. بافتراض 6000 دورة يعطي نظرياً أكثر من 10 سنوات، لكن الحرارة تقلل ذلك، ولذلك أولوية الحماية الحرارية.

## 4. قواعد حماية الأصل

| القاعدة | القيمة المقترحة |
|---|---|
| حد التفريغ الأدنى | 10% |
| سقف الشحن اليومي | 90 إلى 95% (مع موازنة دورية) |
| أقصى تيار شحن | نحو C/3 |
| قطع الشحن حرارياً | فوق نحو 45°م (مع تخفيض تدريجي قبلها) |
| موضع التركيب | مظلل ومهوّى بعيداً عن الشمس والرطوبة |

## 5. الحماية الكهربائية
- قاطع DC وفيوزات على مسار البطارية.
- قاطع AC ومانع صواعق (SPD).
- تأريض وفق الأنظمة المحلية.
- صندوق مختوم للبطارية والمتحكم مع مفتاح عبث.
- قفل على الأقطاب ومنع الوصول المباشر.

## 6. نقاط التحقق قبل التركيب (مسح الموقع)
- قاطع الدخول للوطنية وسعة السلك.
- جودة التأريض.
- موضع آمن وتهوية.
- جودة إشارة WiFi في موضع المتحكم.
- قائمة الأحمال الكبيرة في المنزل.
