# 06 — الأمان والسلامة

## 1. نموذج التهديدات

| التهديد | السيناريو | المعالجة |
|---|---|---|
| سحب خفي من البطارية | إنفيرتر ثانٍ موصول بأقطاب البطارية | صندوق مختوم، ومقارنة تيارين، وموازنة الطاقة، ومفتاح عبث، وشنت مستقل (المرحلة 2) |
| فصل الراوتر | المشترك يفصل الإنترنت ليتجنب القطع | رمز صلاحية موقّع بتاريخ انتهاء، ومهلة قصوى للانقطاع، وخيار 4G |
| إعادة رمز قديم | تسجيل رمز صالح وإعادته لاحقاً | رقم تسلسلي متزايد `seq` وتاريخ انتهاء |
| تلاعب الساعة | تأخير ساعة الجهاز لإطالة الصلاحية | RTC مع عداد أحادي الاتجاه ومزامنة عند كل اتصال |
| تزوير أوامر | مهاجم يرسل أوامر قطع/وصل | أوامر موقّعة، وTLS، وشهادة لكل جهاز، وACL على المواضيع |
| تجاوز الكونتاكتور | توصيل المنزل مباشرة بالإنفيرتر | ختم لوحة التوصيل، وعداد AC يكشف قدرة بلا موافقة، وفحص الموقع الدوري |
| تلاعب البرنامج الثابت | تحميل نسخة معدلة | إقلاع آمن، وصور موقّعة، وتعطيل منفذ التصحيح |
| احتيال الدفع | إعادة إرسال webhook أو تزويره | توقيع، وعدم التكرار، وتحقق مباشر من البوابة |
| تسريب البيانات | بيانات المشتركين | تشفير أثناء النقل وفي التخزين، وأقل صلاحيات، وسجل وصول |
| الحرمان من الخدمة | إغراق الوسيط | حدود معدل لكل جهاز، وفصل عن الواجهات |

## 2. أمان الأجهزة

- **هوية الجهاز:** شهادة X.509 فريدة تُحقن عند التصنيع/التهيئة.
- **الإقلاع الآمن وتشفير الفلاش:** مفعّلان.
- **تعطيل منافذ التصحيح** في الإنتاج.
- **التحديثات الموقّعة** فقط، مع Rollback.
- **سجل أحداث محلي** غير قابل للمسح من المستخدم.

## 3. أمان السحابة

- مصادقة قوية ومتعددة العوامل لمستخدمي اللوحة.
- أدوار وصلاحيات (مشغل، فني، دعم، قراءة فقط).
- سجل تدقيق لكل أمر يُرسل إلى جهاز.
- نسخ احتياطي واختبار استعادة دوري.
- لا تُخزَّن أرقام البطاقات؛ تُدار لدى بوابة الدفع.

## 4. السلامة الكهربائية

| البند | المتطلب |
|---|---|
| التغذية العكسية | منع تغذية الشبكة الوطنية (Zero Export / Anti-islanding)، فهي خطر على عمال الصيانة وغالباً مخالفة |
| حماية DC | قاطع وفيوزات مقدّرة بشكل صحيح على مسار البطارية |
| الحرارة | قطع الشحن فوق الحد، وتركيب مظلل ومهوّى |
| الحريق | مسافة آمنة من المواد القابلة للاشتعال، ومعلومات إطفاء مناسبة، وكاشف دخان عند الحاجة |
| التأريض | وفق الكود المحلي |
| التركيب | فنيون مؤهلون فقط، مع قائمة تحقق موقّعة |
| الصيانة | قطع الطاقة قبل الفتح، وعزل مصادر AC وDC |

## 5. الامتثال
- مراجعة الأنظمة العراقية للكهرباء والبطاريات وأجهزة الاتصال اللاسلكي قبل أي تنفيذ.
- شهادات المنتج (مثل CE/FCC لوحدة WiFi) يغطيها اختيار وحدات مُعتمدة مسبقاً.
- سياسة خصوصية وشروط استخدام للتطبيق.

> هذا قسم تصميمي نظري ولا يغني عن استشارة مهندس كهرباء مرخص ومستشار قانوني محلي.
